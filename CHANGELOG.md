# Changelog

## 1.6
- Настройка «Заголовок»: число строк отдельно для ПК и телефона (0 — без ограничения) и обрезка по целому слову до N знаков с «…».
- Картинка: при пропорции ширина и высота в настройках пересчитываются друг от друга; при «Свой размер» — независимы.

## 1.5
- Лишние закрывающие теги темы (например, `</p>` перед рекламой в SmartMag) пропускаются, как в браузере — раньше из-за них блок не вставлялся.
- Язык записи определяется автоматически (по буквам і, ї, є, ґ), если у сайта нет поля post_lang: правильная подпись и подбор записей на том же языке.
- Без двойников: если заголовок второй ссылки почти совпадает с первой, берётся следующая запись.

## 1.4
- Настройка «Картинка: Показывать» — без галочки блок выводится без миниатюры (картинки нет в HTML).

## 1.3
- Включение автообновлений в списке плагинов (плагин сообщает WordPress, что поддерживает обновления).
- Заголовок Update URI: WordPress не путает плагин с одноимённым из каталога wordpress.org.

## 1.2
- Пропорции миниатюры: 16:9, 4:3, 3:4, 1:1 или свой размер; ширина в px.
- Миниатюра из размера medium с srcset — чёткая на экранах высокой плотности.

## 1.1
- Вставка также в конце раздела: после абзаца перед подзаголовком или коротким абзацем (гороскопы, тексты «подзаголовок — абзац»).
- Настройка толщины линии слева (0 — без линии).
- Эффект картинки при наведении: без эффекта, увеличение, сдвиг, затемнение.
- В «Свой CSS» по умолчанию — пустые правила всех классов блока.

## 1.0
- Первый выпуск.
