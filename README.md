# WebMaster Related

Блок «Читайте также» внутри текста записи WordPress.

- 1 вставка в обычных записях, 2 — в длинных (порог в настройках, по умолчанию 5000 знаков); в записях короче 4 абзацев блока нет.
- Одна ссылка на вставку, с миниатюрой: 16:9, 4:3, 3:4, 1:1 или свой размер (источник — medium + srcset).
- Подбор: общие метки → та же рубрика, за N дней от даты записи (с расширением), язык `post_lang` в приоритете.
- Ставится после абзаца — перед следующим абзацем или подзаголовком; не в первые и последние 2 абзаца, не сразу после заголовка, не рядом с картинками, списками, таблицами, цитатами, блоками «Важно».
- Подборка хранится в записи (`_wmr_ids`), обновляется при сохранении и не чаще раза в 7 дней.
- Только на странице записи: нет в RSS, REST API, архивах, поиске. Без JavaScript.
- Галочка «Без «Читайте также»» в редакторе; исключение рубрик и меток в настройках.
- Клики для GA4 (через GTM): селектор `.wmr-related a, .wmr-related a *`.
- Линия слева настраивается (0 — без линии), эффект картинки при наведении: без эффекта, увеличение, сдвиг, затемнение.
- Обновления из GitHub Releases этого репозитория.

Настройки: **Настройки → WebMaster Related**.
